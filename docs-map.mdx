## Quick Reference

### Endpoints at a Glance

```
GET  /server              Get server info
GET  /bot                 Get bot info
GET  /votes/{id}          Check user vote status
GET  /reviews             Get server reviews
```

**Base URL:** `https://api.rankly.live/api/v1`

**Auth:** Header or query param: `X-API-Key: rk_live_...`

### Webhook Events

```
bot_vote           User voted for bot
premium_purchase   Premium tier purchased
```

### Rate Limit

```
120 requests/minute per API key
```

### Common Questions

**Q: Do I need to use the API or webhooks?**
A: See [API vs Webhooks](/quickstart-api#api-vs-webhooks) comparison

**Q: How do I authenticate?**
A: See [Authentication](/servers/api-reference#authentication)

**Q: How do I handle duplicates?**
A: See [Idempotency](/bots/vote#idempotency--deduplication)

**Q: What's the difference between vote and premium webhooks?**
A: [Vote Webhooks](/bots/vote) are for votes, [Premium Webhooks](/bots/premium) are for purchases

**Q: Can I test webhooks locally?**
A: Yes! Use [ngrok](/quickstart-api#local-testing-with-ngrok)
